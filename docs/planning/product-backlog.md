\# Shelf — Product Backlog



Rough, unrefined, not yet estimated. Grouped by epic for readability, not priority order.



\## Auth

1\. As a user, I can create a profile so my reading data is tied to me.

2\. As a user, I can log in so I only see my own shelf.

3\. As a user, my session persists across app restarts so I don't have to log in every time.



\## Boards \& Cards

4\. As a user, I can see a board representing my whole shelf.

5\. As a user, I can add a book card with a title and author.

6\. As a user, I can move a card between columns (Want to Read, Currently Reading, Finished).

7\. As a user, I can edit a card's details after adding it.

8\. As a user, I can delete a card I no longer want tracked.



\## Book Details \& Notes

9\. As a user, I can give a book a star rating once it reaches Finished.

10\. As a user, I can write short notes or a review for a finished book.

11\. As a user, I can tag a book with a genre.



\## Search \& Filter

12\. As a user, I can search my shelf by title or author.

13\. As a user, I can filter my shelf by genre.

14\. As a user, I can filter my shelf by current reading stage.



\## Reminders

15\. As a user, I get a nudge if a book has sat in Currently Reading past a set number of days.
